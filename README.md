# ToDoList

## Описание

ToDoList — это приложение для управления задачами, написанное на языке Go.

## Технологический стек

- **Бэкенд**: Go
- **База данных**: PostgreSQL
- **Драйвер базы данных**: `github.com/jackc/pgx/v5`
- **Конфигурация**: `github.com/kelseyhightower/envconfig`
- **Валидация**: `github.com/go-playground/validator/v10`
- **Логирование**: `go.uber.org/zap`
- **Тестирование**: `stretchr/testify`
- **Документация API**: Swagger
- **Инфраструктура**: Docker, Docker Compose, Make

## Архитектура

Структура проекта:

- `cmd/todolist/`: Главная точка входа в приложение. Отвечает за внедрение зависимостей, инициализацию сервисов и запуск HTTP-сервера.
- `internal/`: Содержит основную бизнес-логику, организованную по доменным функциям (`users`, `tasks`, `statistics`, `web`). Каждая функция дополнительно разделена на:
  - `repository`: Слой доступа к данным, взаимодействующий с PostgreSQL.
  - `service`: Слой бизнес-логики.
  - `transport_http`: HTTP-обработчики и маршрутизация для API.
- `migrations/`: SQL-миграции схемы базы данных.
- `docs/`: Спецификации Swagger для документации API.
- `public/`: Статические файлы фронтенда.
- `core/`: Настройка HTTP-сервера, промежуточное ПО (CORS, Request ID, логирование, трассировка, восстановление после паник), инициализация пула соединений PostgreSQL и конфигурация логгера.

## Возможности

- Управление пользователями и задачами (создание, чтение, обновление и удаление пользователей/задач);
- Получение статистики на основе данных о задачах;
- Документация API через Swagger;
- Полностью контейнеризированные среды для разработки и продакшена.

## Команды Makefile

Проект включает Makefile для автоматизации распространенных задач разработки, тестирования и развертывания. 

- `make env-up` — Запуск контейнера с базой данных PostgreSQL в фоновом режиме.
- `make env-down` — Остановка и удаление контейнера с базой данных PostgreSQL.
- `make env-cleanup` — Полная очистка данных PostgreSQL.
- `make migration-create seq=<номер>` — Создание нового файла миграции.
- `make migration-action action=<действие>` — Применение или откат миграций.
- `make env-port-forward` — Запуск проброса портов для локального подключения к базе данных извне Docker-сети.
- `make env-port-close` — Остановка проброса портов к базе данных.
- `make logs-cleanup` — Очистка файлов логов приложения.
- `make todolist-run` — Локальный запуск приложения через `go run`.
- `make todolist-deploy` — Сборка и запуск основного контейнера приложения в Docker.
- `make todolist-undeploy` — Остановка и удаление контейнера приложения.
- `make swagger-gen` — Генерация документации Swagger на основе аннотаций в коде в директорию `docs`.
- `make test` — Запуск всех тестов с выводом процента покрытия кода в консоль.
- `make test_html` — Запуск тестов с генерацией детального HTML-отчета о покрытии кода.
- `make ps` — Отображение статуса и информации о текущих запущенных Docker-контейнерах.
